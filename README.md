# Modern JavaScript & ACID Transaction Showcase

A demonstration project exploring modern JavaScript capabilities and robust database operations.  
This repository serves as a sandbox for testing new ECMAScript features alongside MongoDB ACID transactions in a Node.js environment.

## Features

* **Temporal API**: Date and time manipulation using the modern ECMAScript standard.
* **Math.sumPrecise**: Accurate floating-point arithmetic and summation.
* **Set Operations**: Data deduplication and unique value management.
* **ACID Transactions**: MongoDB replica set integration demonstrating Atomicity, Consistency, Isolation, and Durability.
* ...

## Prerequisites

* Node.js (v24.0.0 or higher)
* MongoDB (Configured as a replica set or using MongoDB Atlas)
* npm or yarn

## Installation

```bash
git clone https://github.com/TanMinhh/ecmascript-features-showcase.git
```

## Configuration

Create a `.env` file in the root directory and add your MongoDB connection string:

```text
MONGO_URI=...
```

## Usage

package.json
```bash
npm start
```

# Giới thiệu các tính năng JavaScript mới & Giao dịch ACID

Repo khám phá các tính năng JavaScript hiện đại và thao tác cơ sở dữ liệu, đóng vai trò như một môi trường thử nghiệm cho các tính năng ECMAScript mới cùng với các giao dịch ACID của MongoDB trong môi trường Node.js.

## Tính năng

* **Temporal API**: Xử lý ngày và giờ bằng tiêu chuẩn ECMAScript hiện đại.
* **Math.sumPrecise**: Tính toán số thập phân và tính tổng chính xác.
* **Set Operations**: Quản lý giá trị duy nhất và loại bỏ dữ liệu trùng lặp.
* **ACID Transactions**: Tích hợp MongoDB replica set để mô phỏng tính Nguyên tử (Atomicity), Nhất quán (Consistency), Độc lập (Isolation) và Bền vững (Durability).
* ...

## Yêu cầu hệ thống

* Node.js (v24.0.0 hoặc mới hơn)
* MongoDB (Được cấu hình dưới dạng replica set hoặc sử dụng MongoDB Atlas)
* npm hoặc yarn

## Cài đặt

```bash
git clone https://github.com/TanMinhh/ecmascript-features-showcase.git
```

## Cấu hình

Tạo tệp `.env` trong thư mục gốc và thêm chuỗi kết nối MongoDB của bạn:

```text
MONGO_URI=...
```

## Sử dụng

package.json
